# Outlook (Microsoft Graph) mock

HTTP mock of the Microsoft Graph v1.0 Outlook mail endpoints, serving the fixture in `data/mailbox.json`.

## Run

```
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m mock_outlook
```

Base URL: `http://127.0.0.1:8000/v1.0` (instead of `https://graph.microsoft.com/v1.0`). Swagger UI: `http://127.0.0.1:8000/docs`.
Use `127.0.0.1` rather than `localhost` in clients: on Windows `localhost` tries IPv6 first and adds ~2s per request.

`python demo.py` calls every endpoint and prints the responses.

## Endpoints

| Method | Path | Notes |
|---|---|---|
| GET | `/v1.0/me` | the mailbox owner (`displayName`, `mail`, ...) from the fixture's `owner` |
| GET | `/v1.0/me/mailFolders` | folders with item counts |
| GET | `/v1.0/me/messages` | all folders |
| GET | `/v1.0/me/mailFolders/{id or inbox}/messages` | one folder |
| GET | `/v1.0/me/messages/{id}` | single message |
| POST | `/v1.0/me/messages/{id}/move` | body `{"destinationId": "..."}`, returns 201 and the message with a **new id** |
| POST | `/mock/reset` | mock-only: reload the fixture |

Supported query options: `$top` (default 10), `$skip`, `$orderby`, `$select`. Others (e.g. `$filter`) return 400.
Bodies are HTML by default; send `Prefer: outlook.body-content-type="text"` for plain text.

State is in memory: a restart or `/mock/reset` puts every message back in its original folder.

## Fixture format

`data/mailbox.json` uses Graph field names, except:

- `folder`: initial folder key (`inbox`, `processing`, `done`), turned into `parentFolderId`
- `meetingInfo`: simplified stand-in for the `event` of a meeting request (Graph `event` shapes inside)
- dates are relative to server start: `now-6h`, `now-9d`, `now+4d@09:00` (UTC)

Generated by the server: `id`, `sender`, `sentDateTime`, `createdDateTime`, `lastModifiedDateTime`, `bodyPreview`, `parentFolderId`, `isDraft`, `bccRecipients`.
